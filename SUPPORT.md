# Support

NHPulse is active research software. The preferred support path is a GitHub
issue with enough information to reproduce the problem.

Please include:

- operating system and MATLAB version,
- output from `nhpulseCheckDependencies()`,
- the preset or config fields used,
- the walkthrough cell or function that failed,
- the complete MATLAB error text,
- whether the issue involves synthetic data or private real subject data.

Do not upload real subject MRI, phone/LiDAR scans, animal photos, or other
sensitive data to a public issue. If a problem requires private data to
diagnose, describe the failure with synthetic or redacted products first.
