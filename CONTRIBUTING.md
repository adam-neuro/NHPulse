# Contributing

This repository is currently an active research-software release candidate.
Issues, bug reports, documentation fixes, and small test cases are welcome.

Before opening a pull request:

1. Keep generated subject data, lead fields, ROAST work directories, STL
   products, and local path files out of git.
2. Prefer small, focused changes with a short description of the use case.
3. Add or update documentation when changing workflow behavior.
4. Use synthetic or dummy data for examples unless a public data source is
   explicitly documented.

For now, MATLAB style follows the surrounding code. The project is expected to
gain automated tests and a smaller synthetic demonstration dataset during initial development.
