# TAZ Pro Dual-Extrusion Printing Helpers

This folder contains optional fabrication helpers used during NHPulse
development with a LulzBot TAZ Pro dual-extruder setup.

- `patch_tazpro_dual.py` patches Cura-style G-code for a startup wipe/home
  issue observed on one development printer.
- Future small slicer-profile or project-template files can be placed here if
  they do not contain subject-specific geometry.

See [../../docs/fabrication.md](../../docs/fabrication.md) for the tested
hardware configuration and use notes.
