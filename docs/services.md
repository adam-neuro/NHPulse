# Stable Pipeline Services

NHPulse service functions are the programmatic boundary used by scripts and a
future integrated application. They do not read variables from the MATLAB base
workspace. Every service receives an explicit project context, an `inputs`
struct containing registered artifact keys or handles, and a `config` struct.
Each successful service returns a `nhpulse.serviceResult` containing the
computational result and newly registered artifact handles.

## Context And Inputs

```matlab
context = nhpulseCreateProjectContext(outputRoot, 'subject01-cap-v1', ...
    'runLabel', 'Subject 01 cap, version 1', ...
    'metadata', struct('subjectId', 'subject01'));

nhpulseRecordArtifact(context.projectRoot, context.runId, 'anatomy', ...
    'nhpulse.anatomy', t1File, ...
    'runLabel', context.runLabel, 'runMetadata', context.metadata);
nhpulseRecordArtifact(context.projectRoot, context.runId, 'segmentation', ...
    'nhpulse.segmentation', maskFile, ...
    'parentKeys', {'anatomy'}, 'parentRoles', {'sourceAnatomy'});
```

Artifact keys are stable within a run. Services reject missing, stale, or
incompatible inputs before invoking an expensive engine.

## Geometry Services

```matlab
scalpStage = nhpulseServiceBuildScalp(context, ...
    struct('segmentation', 'segmentation'), struct('showFigures', true));
cropStage = nhpulseServiceCropScalp(context, ...
    struct('scalp', scalpStage.artifacts.scalp), ...
    struct('cropPlaneMode', 'autoSelect', 'showFigures', true));
exclusionStage = nhpulseServiceDefineExclusions(context, ...
    struct('scalp', cropStage.artifacts.scalp), ...
    struct('editMode', 'auto', 'showFigures', true));
```

`nhpulseServicePlaceHeadpost` consumes a registered implant trace, scalp, and
segmentation and returns both placement and keepout artifacts.
`nhpulseServiceBuildFitCheck` consumes a registered layout and those same
geometry/exclusion handles to produce a quick PLA fit-check STL.

`nhpulseServiceDefineFiducials` accepts a scalp artifact and either opens the
picker or saves explicitly supplied coordinates. `nhpulseServiceSelectTarget`
accepts anatomy and segmentation artifacts and either opens the target picker
or registers a supplied target voxel. Interactive decisions therefore use the
same explicit service contract as automated stages.

## Modeling And Layout Services

```matlab
layoutInputs = struct('anatomy', 'anatomy', ...
    'segmentation', 'segmentation', ...
    'scalp', cropStage.artifacts.scalp, ...
    'anatomicalExclusion', exclusionStage.artifacts.exclusions);
layoutStage = nhpulseServiceBuildCandidateLayout(context, layoutInputs, ...
    struct('nElectrodes', 16));

leadFieldStage = nhpulseServiceGenerateLeadField(context, ...
    struct('layout', layoutStage.artifacts.layout, ...
    'segmentation', 'segmentation'), ...
    struct('mode', 'roast', 'simulationTag', 'subject01_lf16'));

optimizationStage = nhpulseServiceOptimizeMontage(context, ...
    struct('leadField', leadFieldStage.artifacts.leadField, ...
    'target', 'stimulation-target', ...
    'layout', layoutStage.artifacts.layout), ...
    struct('activeElectrodeCount', 8, 'totalCurrentMa', 2));
```

Additional growth rounds use `nhpulseServiceGrowCandidateLayout`; its returned
layout handle can be passed directly to the lead-field service for the next
iteration.

`mode='dummy'` is intended only for software testing.

## Final Layout And Manufacturing

```matlab
combinedStage = nhpulseServiceBuildCombinedLayout(context, ...
    struct('layout', layoutStage.artifacts.layout, ...
    'montage', optimizationStage.artifacts.montage, ...
    'scalp', cropStage.artifacts.scalp, ...
    'anatomicalExclusion', exclusionStage.artifacts.exclusions), ...
    struct('nTes', 8, 'nEeg', 8));

retentionStage = nhpulseServicePlanRetention(context, ...
    struct('layout', combinedStage.artifacts.layout, ...
    'scalp', cropStage.artifacts.scalp, ...
    'anatomicalExclusion', exclusionStage.artifacts.exclusions), ...
    struct('editMode', 'auto'));

manufacturingStage = nhpulseServiceBuildManufacturing(context, ...
    struct('layout', combinedStage.artifacts.layout, ...
    'scalp', cropStage.artifacts.scalp, ...
    'anatomicalExclusion', exclusionStage.artifacts.exclusions, ...
    'retentionPlan', retentionStage.artifacts.retentionPlan), ...
    struct('force', false));
```

Common settings have stable top-level names. Less common engine options can be
supplied in `config.engineOptions`; service-owned paths and provenance remain
under service control. Run `nhpulseTestServiceLayer` for a fast contract test.
